What Walrus Memory does with a sentence

A memory layer for agents. You hand it text; it embeds, encrypts and stores the bytes on Walrus, and keeps a searchable vector pointing back at them. Recall is semantic search, not a key lookup.

remember("prefers Vietnamese")
→
Relayer

what makes it findable later
Measured end to end: 23.7 seconds. Too slow to await inside a chat turn, so writes are fire-and-forget with a pending state the user can see.
Read
recall("what language?")
→
Semantic search
nearest vectors in this namespace
→
text + distance, ranked
injected into the prompt as untrusted data
Nothing is keyed by id. You ask in the words the user just used, and the store decides what is close enough.
Who owns it
A MemWalAccount object on Sui. It belongs to a wallet, not to the app.
Who can reach it
Holders of a delegate key the owner registers — and can remove.
What separates users
The pair owner + namespace. That is the whole isolation boundary.
What it costs
The managed relayer pays storage from its own wallet. No token to hold.
