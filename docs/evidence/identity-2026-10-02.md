# hippo's identity and the recalled-memory block — 2026-10-02

## What was wrong

- 2026-09-30, local stack, `google/gemini-2.5-flash`: asked "xin chào, bạn là ai?", hippo answered "Tôi là Gemini, một mô hình ngôn ngữ lớn, được đào tạo bởi Google." The system prompt opened with "You are hippo" and the model ignored it.
- 2026-10-02, `bun run demo` on `deepseek/deepseek-v4.1-flash` (`demo-2026-10-02-deepseek-v4.1-run1.txt`, session one): three replies talked to the user about the recalled-memory block as if they had pasted it ("The nonce block is just recall output", "Khối nonce bạn dán chỉ là dữ liệu recall"). The block is inserted by hippo as a user-role message before the latest message (`runTurn` in `packages/core/src/agent.ts`). The demo's assertions do not look for this.

## Change

`packages/core/src/prompt.ts`: an IDENTITY paragraph (hippo, not the model; never Gemini, DeepSeek, Qwen or a model company; name OpenRouter only when asked which model writes the text), and one sentence in RECALL saying hippo inserts the block, the user did not write it and cannot see it, and it is never mentioned. `packages/core/src/prompt.test.ts` checks both are present.

## Check

One-off probe, not in the repo: `completeTurn` with the real model through OpenRouter and a fake memory port that returns two memories, so the block is injected on every turn. Nothing touched the relayer. Memory on, session start. A reply fails if it matches `gemini|deepseek|google|nonce|BEGIN_UNTRUSTED|END_UNTRUSTED|khối|you pasted|bạn dán`.
