# The web UI, checked against production

Verified in a real browser against https://hippo-web-ten-nu.vercel.app on
2026-09-22, after deploying both services. Typecheck and a green build say
nothing about what a visitor sees, so each item below was clicked.

## The landing section

Opening the site now leads with the claim rather than an input box: "A chatbot
that remembers you, on memory you own", the three steps behind it, and hippo's
own account linked on Sui.

```
Until you connect a wallet, your memory lives under hippo's own account,
0x5a257802…, on Sui mainnet.
```

The link resolves to the real object on Suiscan. The section disappears once
there is a conversation, so it never pushes replies below the fold.

## Dark mode

The palette had been in `index.css` from the start with nothing ever applying
the class. The page now follows the system preference on first visit, which is
what the screenshot above shows, and remembers an explicit choice. A script in
the head decides before first paint so there is no white flash.

## Update 2026-09-23: steps, live numbers, and a lesson about the instrument

The three equal cards became a numbered sequence, and a strip of real numbers
went under it, read from `GET /api/stats`. Verified on production in both
themes: headline resolved, three steps in order with their command badges, and
`13 memories · 5 people · on 0x5a257802…` linked to Suiscan.

**A caution for anyone testing this the same way.** Scaled full-page screenshots
through the browser extension made the landing look broken: steps faded or
missing, and once a headline frozen mid-animation. Zooming into the same region
at the same moment showed everything rendered solid. The capture evidently
repaints the page and restarts mount animations, so it catches them mid-flight
every time.

Two changes were made while chasing that. Both are defensible on their own
terms and neither is a proven user-visible fix:

- `DecryptedText` guards its replay with a ref rather than state. The effect it
  lives in depends on a callback rebuilt whenever an animation flag flips, so a
  re-render re-subscribes and a new observer fires at once on an element already
  on screen; state has not committed inside that window. The latch closes the
  race whether or not it was ever hit in practice.
- The steps animate on mount rather than on scroll into view. They are never
  below the fold, so waiting for an intersection buys nothing.

Recorded because the honest version is more useful than "fixed two bugs": the
evidence was contaminated, and the second measurement is what showed it.
