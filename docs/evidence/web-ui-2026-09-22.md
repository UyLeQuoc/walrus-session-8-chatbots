# The web UI, checked against production

Verified in a real browser against https://hippo-web-ten-nu.vercel.app on
2026-09-22, after deploying both services. Typecheck and a green build say
nothing about what a visitor sees, so each item below was clicked.

## The landing section

Opening the site now leads with the claim rather than an input box: "A chatbot
that remembers you, on memory you own", the three steps behind it, and hippo's
own account linked on Sui.

```
Until you connect a wallet, your memory lives under hippo's own account,
0x5a257802…, on Sui mainnet.
```

The link resolves to the real object on Suiscan. The section disappears once
there is a conversation, so it never pushes replies below the fold.

Searching "how do I deploy" returned the memories themselves, ranked, each
linking its blob. The text cannot come from Postgres, which holds no memory
text, so this is a real read back from Walrus:

one.

## Dark mode

The palette had been in `index.css` from the start with nothing ever applying
the class. The page now follows the system preference on first visit, which is
what the screenshot above shows, and remembers an explicit choice. A script in
the head decides before first paint so there is no white flash.
