## 3. Web on Vercel

The Vercel project uploads `apps/web` alone (root directory `.`), and the web
app now imports `@hippo/core` from the workspace. So it was built where the
workspace exists and shipped prebuilt, from `apps/web`:

```bash

vercel build --prod
vercel deploy --prebuilt --prod --yes
```

The output keeps the `/api/*` rewrite to Railway. Aliased to
https://hippo-web-ten-nu.vercel.app.
