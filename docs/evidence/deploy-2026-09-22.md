## What was checked, not assumed

**The image did not build.** It ran `pnpm typecheck`, which includes the test
files, and the production image installs no `vitest`. A deploy would have failed
on a problem a deploy cannot fix. Removed; CI runs typecheck and tests on every
push. Verified instead by building the image and running it locally before ever
pushing it.

**The build context carried secrets.** No `.dockerignore` existed, so the daemon
received `memwal/` (71 MB), every `node_modules` (463 MB) and `.env`. Added one;
confirmed afterwards that neither `.env` nor `memwal/` exists inside the image.

**Deploys no longer touch the schema.** `railway.toml` was running
`drizzle-kit push --force` on every deploy. Push can drop a column to reach the
target schema, and this database holds users' encrypted delegate keys. Schema
changes now go out deliberately.

**CORS was wrong on the first try**, which is exactly the failure that makes a
deployed bot look like it has amnesia: without the right origin the browser's
cookie never arrives, so every request is a new stranger. Confirmed after fixing:

```
Origin: https://hippo-web-ten-nu.vercel.app  → access-control-allow-origin present
Origin: https://evil.example                 → absent
```

## End to end on the deployed stack

```
POST /api/chat  "Remember this: my favourite fruit is mangosteen and I deploy on Railway."
  → wrote 2 memories, both reached Walrus:
    IkAsqpznAq8R…  NK3jxghQkT_3…

POST /api/chat  "What is my favourite fruit and where do I deploy?"   (sessionStart, no history)
  → "Your favorite fruit is mangosteen and you deploy on Railway."
  → recalled: [{profile, "my favourite fruit is mangosteen", 0.49, IkAsqpznAq8R…},
               {profile, "I deploy on Railway", 0.32, NK3jxghQkT_3…}]
```

The cookie came back `Secure; HttpOnly; SameSite=Lax`, and the reply carried the
memories it was built from, so the page can show them.

## One replica, on purpose

Telegram long polling from two processes fights over the same updates, so
`railway.toml` pins `numReplicas = 1` and the local dev server must be stopped
while production is running.
